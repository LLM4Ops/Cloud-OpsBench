# Fault Knowledge Base

This directory provides reference knowledge templates for 40 of the benchmark's 57 fault types. Each entry describes the fault mechanism, sub-scenarios, trigger conditions, prerequisites, configuration snippets, and injection commands.

Snippets may be partial manifests and contain placeholders that must be adapted to the target environment. These are fault-type templates, not complete per-case injection records or standalone executable manifests.

Use these materials to reproduce or extend the benchmark; keep them outside the diagnostic agent's inputs. The remaining 17 fault types are not included in this release.
